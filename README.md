# Castle C: The Sound Crystal Quest

A bilingual English/Traditional Chinese browser game for Grade 5 learners to distinguish soft c `/s/` and hard c `/k/`.

## Run locally

Serve the `dist` directory with any static web server. The game uses browser speech synthesis for English word pronunciation.

## Main interactions

- Three progressive levels: 3×3, 4×4 and 5×5.
- English speech, bilingual interface text.
- Separate background-music and sound-effect toggles.
- Correct, incorrect/hands-over-head, and celebration mole states.
- Progress is stored locally in the browser.

## Asset provenance

- Visuals: generated with the built-in OpenAI ImageGen route, using the approved clay-castle concept as a style reference.
- Background music: user-provided `BG Misic.mp3` (used as background music).
- Sound effects: Sound Effect Lab. See `CREDITS.md`.
